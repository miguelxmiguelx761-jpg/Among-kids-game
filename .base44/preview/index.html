Telas do app

Estas são as telas reais do app Android, renderizadas a partir do código atual com o Robolectric + Roborazzi que já fazem parte do projeto (app/src/test/java/com/example/preview). Um app Android nativo não roda dentro do navegador e este ambiente não tem aceleração de hardware para um emulador — por isso o preview mostra as telas renderizadas. Ao salvar qualquer arquivo em app/src, elas são reconstruídas automaticamente aqui.
